### 🚀 Sobre o Projeto
Este projeto consiste na criação de **slides programados por código** para a apresentação e defesa do TCC do Ensino Médio. Em vez de utilizar ferramentas tradicionais de diapositivos, a aplicação foi construída com tecnologias modernas de desenvolvimento web, garantindo fluidez, componentes reutilizáveis, design responsivo e uma estética altamente profissional.

---

### 💻 Tecnologias Utilizadas
- **Vue.js** — Framework principal para estruturação de componentes dinâmicos e gestão dos slides.
- **TypeScript** — Tipagem estática para maior segurança e robustez no código.
- **CSS3** — Estilização avançada, transições e layout personalizado para cada diapositivo.

---

### ✨ Funcionalidades
* **Navegação Sequencial:** Estrutura organizada por páginas/slides (`/1`, etc.) para acompanhar o fluxo da apresentação.
* **Componentes Modulares:** Organização avançada de código com componentes reutilizáveis (`components/`, `pages/`, `snippets/`).
* **Design Responsivo:** Adaptado para exibição perfeita em projetores e ecrãs durante a defesa do trabalho.
